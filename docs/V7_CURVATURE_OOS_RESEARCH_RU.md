# V7 — оптимизация кривизны V6, real-hard-USDC OOS и данные рынка

Статус: **RESEARCH / NOT DEPLOYABLE**. Продолжение PR #8; главный пул main не менялся, ИИ-ЦБ не интегрирован.

## Инвариант сохранён
Единое path-independent `F(x)`, цена = производная; две кривизны. Oracle band до/после сделки ±1%. Динамическая комиссия покупки 8–18% от реальных USDC, фиксированная комиссия продажи 1.5%, 30% комиссии Owner (реальный USDC), 70% retained pool (не суммировать дважды к NAV).

### Конкурентоспособность комиссии
В отдельном эксперименте с тем же математическим инвариантом, при внешнем CPMM 2500 SYNA, 50/50 поток, 8 новых seed:
- комиссия 8–18%: Owner 5.36 USDC, исполнено 1.73%, Hard USDC 8827.74;
- комиссия 1%: Owner 38.83 USDC, исполнено 19.04%, Hard USDC 10279.60;
- комиссия 0.3%: Owner 36.92 USDC, исполнено 35.58%, Hard USDC 10415.83.

Это отдельное исследование, комиссия текущего контракта V6/V7 **НЕ изменена**. Процент распределения 30/70 сохранён.

### Исторические данные / источник риска
Binance market-data connector: 337 настоящих часовых ETHUSDT candles 2026-10-01..15, 57 шестичасовых sample. На статическом якоре 1 и полосе ±1% 39/57 sample оказываются вне band. **Это ETHUSDT, не SYNA, не исторические on-chain блоки, а объём свечи не равен доступной внешней глубине**. Исторические Polygon `eth_call getReserves` для точного SYNA/USDC пока не удалось проверить: нет архивного RPC + адреса независимого достаточно ликвидного пула.

Собственный инструмент проверки токенов в `synergy_ai_financial_system/scripts/check_polygon_balances.py` использует адрес SYNA `0xaeB98101e29E791A2482C2A5B55F444F6C9E44a4`. Нельзя брать цены других тикеров SYNA как цены этого токена.

# SYNERGY Recursive Asymmetric AMM V6 — oracle band / research

**Статус: проектирование / не развёртывать.** Это изолированный PR для проверки политики ценового диапазона. Он НЕ заменяет `src/CPMMPool.sol` и не меняет действующие пулы.

## Уязвимость, требующая защиты

Математическая ошибка оригинального RecursiveAsymmetricAMM с выплатой 24 477 USDC за 1 SYNA исправлена в отдельном прототипе V5. Однако после семи покупок 500+900+1500+2500+4000+6500+10000 USDC внутренний spot модели поднимался до ~16.3943 USDC/SYNA при внешней цене 1 USDC/SYNA. В условном арбитраже продажа ~2700.53 SYNA забирала 22060.79 USDC из пула, давая ~19360.26 USDC валовой прибыли при закупке SYNA снаружи по 1 USDC.

## V6: независимая цена и ограничения исполнения

Сохранить исходную кривую, комиссии покупки 8–18%, продажи 1.5%, деление 30% Owner / 70% retained pool. Добавить проверку не текущего TVL, а внешней котировки SYNA/USDC:

```
require(Pext * 0.99 <= P_before && P_before <= Pext * 1.01);
require(Pext * 0.99 <= P_after  && P_after  <= Pext * 1.01);
```

Покрыть **все** публичные пути обмена: `buy`, `buyExactOut`, `sell`, `quoteBuyExactOut`, `quoteSell` и первоначальную инициализацию. Контрактную проверку допустимо реализовывать через `OracleBandPolicyV6` из `src/OracleBandPolicyV6.sol`. Не использовать цену самого пула в качестве оракула.

Без обеспечения внешнего корректного ликвидного курса SYNA/USDC эта защита не может быть включена безопасно. В частности, когда внешняя цена изменяется на >1%, торговля может блокироваться до выравнивания рынка или изменения архитектуры. Нельзя производить произвольный recentering, выдавая его за восстановление HardNAV.

## Воспроизведённые результаты Python (локально, не EVM)

- 17/17 property-тестов пройдены;
- при band ±1% максимально допустимая первоначальная покупка лишь ~2.0923 SYNA;
- первоначальная продажа допускает ~140.3025 SYNA;
- первая покупка на 500 USDC отклоняется, поскольку её post-spot был бы ~2.3012;
- 30 сценариев по 2500 случайных заявок: медиана принятых ~75.44%, медиана консолидированного USDC ~10103.99 (старт 10000), медианный полученный Owner USDC ~30.84;
- 100%-ный поток продаж может уменьшить USDC; 100%-ный поток покупок быстро упирается в ценовой коридор. USDC никогда не создаются внутренней формулой.
